# 📋 О проекте

**АРГУС** — современная веб-платформа для управления учебным расписанием, анализа нагрузки преподавателей и интеллектуальной обработки данных учебного процесса.

Система разработана для локального использования в образовательных учреждениях и поддерживает масштабируемую архитектуру с AI-модулями, аналитикой и рекомендательной системой.

---

# 🎯 Основные возможности

| Модуль | Возможности |
|--------|-------------|
| 📅 **Расписание преподавателей** | Визуализация расписания по дням и месяцам, фильтрация по ПМК и факультетам, множественный выбор преподавателей, копирование и вставка пар, замена преподавателей |
| 📊 **Анализ нагрузки** | Детальная статистика по преподавателям, интерактивные графики (Chart.js), экспорт в Excel, разбивка по факультетам |
| 🤖 **AI Ассистент** | Ответы на вопросы о расписании, самообучающаяся NLU-модель, human-like ответы, контекстные диалоги |
| 💡 **Рекомендательная система** | Алгоритм Жаккара, ML-модель с весами, поиск замен преподавателей, адаптивное обучение |

```bash

```

## Сохранение образа

```bash

```

## Загрузка образа

```bash
docker load -i schedule_v24.tar
```

